Outlook section (40 min)

Mailbox load steps Booking summary attachment
O1 Summarize long thread
WHERE THIS PROMPT HAPPENS: Outlook in folder Shipment Delay Thread (imported from thread-eml).
Summarize this shipment-delay thread for me:
1) What decisions were made?
2) What is still open?
3) Who owns each open item and by when?
Return a concise status update I can send to head office in under 180 words.
O2 Draft revised appointment reply
WHERE THIS PROMPT HAPPENS: Outlook reply window with Weekly-Auto-Service-Booking-Summary.docx attached.
Draft a reply to affected customers confirming revised appointment times.
Reference the attached Weekly-Auto-Service-Booking-Summary.docx and include:
- confirmation of the new date/time,
- a brief apology,
- what to do if the new time does not work.
Keep it clear, professional, and in plain en-CA language.
O3 Coaching + empathy rewrite
WHERE THIS PROMPT HAPPENS: Outlook in the draft created from O2.
Use Copilot coaching to review this reply for tone and clarity.
Then rewrite it to sound more empathetic while staying concise and professional.
Keep all operational commitments unchanged.
O4 Schedule follow-up meeting + agenda
WHERE THIS PROMPT HAPPENS: Outlook thread view in Shipment Delay Thread.
From this email thread, create a follow-up meeting invite for key owners this week.
Include:
- a 30-minute meeting title,
- required attendees,
- 4 agenda bullets focused on decisions, open risks, and next actions.
O5 Messages needing action today
WHERE THIS PROMPT HAPPENS: Outlook Inbox with both Shipment Delay Thread and Other Messages loaded.
Based on today’s inbox and the shipment thread, tell me which messages need action today.
Group as:
1) urgent today,
2) today if time allows,
3) FYI only.
For each action item, include one suggested next step.

Learner question: Which Copilot output would you send as-is, and which would you always revise first?

Teams section (40 min)

Context change: district call + channel catch-up
Meeting script Fallback transcript (.vtt) Fallback transcript (.docx) Channel posts script Expected recap reference
T1 Catch up on channel
WHERE THIS PROMPT HAPPENS: Teams district channel after seeding posts from District-Channel-Posts-Script.md.
Catch me up on this district channel for the past week.
Summarize major updates and highlight anything that needs my reply today.
Return:
- 5-7 bullet summary
- a “Needs my reply” list with who to respond to and why
T2 Recap meeting and action table
WHERE THIS PROMPT HAPPENS: Teams meeting recap context (live transcript) or fallback transcript file loaded in Teams/Chat.
Recap this winter-readiness meeting.
Give me:
1) key decisions,
2) action items in a table with Owner | Action | Due date | Status,
3) one-sentence executive takeaway.
T3 Disagreement + unresolved follow-up
WHERE THIS PROMPT HAPPENS: Same meeting context as T2 (do not switch source).
From the meeting, where did people disagree and what is still unresolved?
List:
- disagreement points,
- options proposed,
- unresolved question(s),
- what input is needed to close them.
T4 Draft and rewrite channel post
WHERE THIS PROMPT HAPPENS: Teams channel composer with recap output from T2/T3 available.
Draft a district channel post from the meeting recap for store teams.
Then rewrite it to be shorter and friendlier while keeping all critical actions and dates.
T5 Optional live late-join prompt
WHERE THIS PROMPT HAPPENS: Live Teams meeting where transcription is on (or fallback transcript if no live meeting).
I joined this meeting a few minutes late.
What did I miss so far?
Give me:
- key points already covered,
- decisions made,
- any action assigned to me.

Learner poll/chat question: What Teams Copilot task saves you most time: catch-up, recap, or rewrite?

Storyline

Outlook: delayed tire shipment + overbooked appointments + weekly head-office status request.

Teams: district weekly winter-readiness call plus daily channel updates and follow-ups.

Prep checklist

  1. Import Outlook `.eml` files in order and verify folders are complete.
  2. Keep booking summary `.docx` ready to attach for O2.
  3. Seed Teams channel posts before the session.
  4. Record meeting script with transcription on; keep fallback `.vtt` and `.docx` ready.
  5. Reset mailbox/channel content before each new delivery.
