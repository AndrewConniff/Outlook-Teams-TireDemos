Outlook follow-along (40 min)

O1 Personalize update style
WHERE THIS PROMPT HAPPENS: Outlook, in a real status/coordination thread you already have.
Based on this thread, draft updates in my preferred style:
- concise first paragraph
- action items in bullets
- clear owner and due date per action
- friendly but direct tone
O2 Summarize attached document and draft send
WHERE THIS PROMPT HAPPENS: Outlook new email draft, with Winter-Tire-Delay-Briefing.docx attached.
Draft an update email to store operations, auto service, and district leadership.
Summarize the attached Winter-Tire-Delay-Briefing.docx in 5 bullets, then include:
1) current status
2) risks
3) actions by owner
4) what support is needed
Use clear en-CA language.
O3 Coaching for clarity and tone
WHERE THIS PROMPT HAPPENS: Outlook, in the draft generated from O2.
Coach this draft for clarity and tone.
Then rewrite it to be slightly warmer while keeping the same commitments and dates.
O4 Schedule follow-up meeting + agenda
WHERE THIS PROMPT HAPPENS: Outlook, same thread/email context as O2.
Create a 30-minute follow-up meeting from this thread/update.
Include required attendees and an agenda with:
- decisions needed
- risk review
- next-week milestones
- owner check-in
O5 Analyst chart handoff email
WHERE THIS PROMPT HAPPENS: Outlook, after pasting one chart image from Excel into draft.
Using the summary below and the chart image I inserted from Excel,
draft a short executive email with:
- 3 key findings
- 2 actions
- 1 ask

Learner check: Which Outlook prompt would you use first in your daily workflow?

Teams follow-along (40 min)

Use your own attended meeting with transcript/recording if available.
T1 Meeting recap from transcript
WHERE THIS PROMPT HAPPENS: Teams meeting recap for a meeting you attended with transcript/recording.
From this meeting transcript/recording, give me:
1) key decisions
2) action items with owner and due date
3) unresolved questions
T2 Follow-up analysis
WHERE THIS PROMPT HAPPENS: Teams, same meeting recap context as T1.
Where did attendees disagree, what options were proposed, and what input is needed to close the open items?
T3 Suggested prompts for Teams calls
WHERE THIS PROMPT HAPPENS: Teams meeting recap pane or Copilot in Teams chat.
Create 6 follow-up prompts I can use in Teams after meetings:
2 for recap, 2 for action tracking, 2 for executive communication.
T4 Share Outlook/Analyst summary to Teams
WHERE THIS PROMPT HAPPENS: Teams channel post composer, with Outlook summary text available.
Draft a Teams channel post from my Outlook update and chart summary.
Then rewrite it in a shorter, friendlier style for store teams.
Keep actions and dates intact.
T5 Optional live late-join
WHERE THIS PROMPT HAPPENS: Live Teams meeting with transcript on.
I joined late. What did I miss so far, and do I have any assigned action?

Learner poll: Recap, follow-up prompts, or channel rewrite — which is most useful for you?

Storyline

Follow-along scenario: use your real Outlook/Teams collaboration data to run Copilot workflows for winter-readiness communication. Optional sample data supports attachment summarization and Analyst chart examples without relying on downloaded conversation packs.

Prep checklist

  1. Pick one real Outlook thread and one real Teams meeting with transcript/recording.
  2. Upload sample shared docs to OneDrive/SharePoint for attachment practice.
  3. Open Excel sample file and create one chart using Analyst/Copilot.
  4. Paste chart once into Outlook draft and once into Teams post draft.
  5. Use only fictional/sample content in public demonstration outputs.
